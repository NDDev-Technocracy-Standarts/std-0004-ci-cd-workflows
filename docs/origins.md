`481fc9e5e8411106a1f6effcd9372784b0f3f245` was inspected alongside the separately archived
`ci-workflows-20261014` and `cd-workflows` native contracts. Useful mechanisms retained in the design
are locked native tool execution, explicit interpreter selection, environment-based shell inputs,
mode-preserving tar artifacts and scoped target serialization.

This implementation does not copy their policy/evidence platforms, paid capability tiers, unbounded
optional matrices, deployment approval/state machine or hosted private Linux prelude. The runtime and
entrypoints are newly implemented here; no historical third-party code files are vendored. External
actions remain separately licensed dependencies, pinned to maintained full commits. Their own packages
and notices remain in their original distributions. No archive release or existing consumer was changed.

The author's canonical standard compilation uses the authorized STD-0000 tool in its private integration
path. Public runtime installation, native tests and consumer invocation do not require that tool or any
private standard corpus. Compiler-generated output in this repository derives from this repository's
own normative source.
