# Security reporting

Report a suspected vulnerability through [Report a vulnerability](https://github.com/NDDev-Technocracy-Standarts/std-0004-ci-cd-workflows/security/advisories/new).
The repository owner, [rldyourmnd](https://github.com/rldyourmnd), triages private reports.

Include the affected source or package identity, impact, and a minimal reproduction. Keep credentials
and private consumer data out of the reproduction. The maintainer reviews the report, requests any
missing evidence, and coordinates remediation and disclosure through the private advisory. Response
and publication timing are agreed there; this project promises no fixed response interval.

Use public Issues for ordinary bugs and questions that do not expose a vulnerability.
